白樺クエスト 操作マニュアル

アカウント登録からリファーラルさがしまで、デモで見せる6つの操作を順番にまとめています。上のタブから該当の項目へすぐに移動できます。

① アカウント登録 ② ログイン ③ Google/Zoom連携 ④ 1to1の主催 ⑤ 複数人ミーティング ⑥ 協働・パワーチーム ⑦ リファーラルさがし
1

アカウント登録

新しく招待されたメンバーが、自分の名刺カードから登録する流れです。なりすまし防止のため、最後は管理者の承認待ちになります。

🔗 入口：/register（招待リンクまたはログイン画面の「新規登録」）
  1. 名刺カードを撮影する配布された物理カードをカメラで撮影、またはギャラリーから画像を選択
  2. AIが自動で読み取る（OCR）表面の「USP・SKILLs」3項目を自動で読み取る。読み取れなかった場合は次のステップで手入力できる
  3. 読み取り内容を確認・修正するスキル名・課題シーン・結果の文章を必要に応じて編集
  4. 氏名・ふりがな・メールアドレスなど基本情報を入力する
  5. 事業内容・カテゴリー、金の卵／金のガチョウ（任意）を入力する「どんな人を紹介してほしいか」「どんな人脈が欲しいか」を登録しておくと⑥のリファーラルさがしで使われる
  6. メールに届いた確認コードを入力する
  7. 管理者の承認を待つ管理画面の「メンバー管理」で承認されると利用開始
💡デモでは、実際に手元のカードを撮影して読み取り精度を見せると分かりやすいです。承認待ちの状態が伝わるよう「まだこの時点ではログインできない」ことも一言添えると親切です。
2

ログイン

パスワードは存在しません。メールで届く確認コードだけでログインする、パスワードレス方式です。

🔗 入口：/login
  1. メールアドレスを入力する
  2. 届いた確認コードを入力する数分で失効するため、その場でメールを確認してもらう
  3. ホーム画面が表示されるやること・直近の1to1・現在のポイントなどがまとめて確認できる
💡「パスワードを覚える必要がない」点が、IT が苦手な方にも安心なポイントとして強調しやすいです。
3

Google/Zoom連携の設定

1to1・ミーティングの日程調整を自動化するには、事前にこの連携が必要です。「Googleカレンダーで選んでもらう」方式や、会議URLの自動発行を使う場合は必須になります。

🔗 入口：マイページ → 「日程調整設定」 → 「🔗 外部サービス連携」（/scheduler/integrations）
Google連携

📅 Googleカレンダー

連携すると、空き時間の自動確認・Google Meet URLの自動発行・Googleカレンダーへの予定自動登録ができるようになる。「連携する」からGoogleアカウントの認可画面へ進む。

Zoom連携

🎥 Zoom

連携すると、Zoomミーティング URLの自動発行ができるようになる。「連携する」からZoomアカウントの認可画面へ進む。

  1. マイページを開く
  2. 「日程調整設定」をタップする
  3. 「🔗 外部サービス連携」を開く
  4. Google・Zoomそれぞれの「連携する」から認可画面に進み、許可する
  5. 連携が完了すると、④1to1・⑤ミーティングで自動化された選択肢が使えるようになる
💡デモではこの連携を先に済ませておくと、④・⑤で「公開予約URLを使う」「AIで探す」「会議URL自動発行」までスムーズに見せられます。連携なしでも、候補日を手動で提示する方式・会議URLの手入力で進行することは可能です。
4

1to1の主催

「なかま」タブからメンバーを選び、1to1を申し込みます。日程の決め方は2種類あり、その場で選べます。

🔗 入口：なかま → 対象メンバー詳細 → 「🤝 1to1を申し込む」
方式A

📅 Googleカレンダーで選んでもらう

「公開予約URLを使う」を選択。自分のGoogleカレンダーと連携済みの場合のみ選べる。自分の空き時間がそのままURLになり、相手がその中から都合の良い枠を選ぶ。

方式B

🗓 候補日を伝えて選んでもらう

「候補日を選んで提示する」を選択。自分で2〜5件の候補日時を用意（カレンダーから選ぶ／手入力の両方に対応）し、相手はその中から1つ選ぶだけでよい。

  1. 日程の決め方（方式A／B）を選ぶ
  2. （方式Bの場合）候補日時を2〜5件入力する
  3. 送信すると相手に通知される相手が枠・候補日を選んだ時点で日程が確定し、会議ツール（Zoom／Google Meet）と連携していればURLも自動発行される
  4. 実施後、どちらか一方が「完了」を記録する両方の記録は不要。どちらかが完了を押した時点でポイントが加算される
💡すでに口頭やメールで日程調整済みの相手には、詳細画面の「📅 すでに日程調整済み？日時を指定して申し込む」から直接確定できます。この場合、相手は都合が悪いときだけ辞退すればよく、承諾操作は不要です。
5

複数人でのミーティングの主催

パワーチームでの定例会や、複数人での打ち合わせを主催する流れです。候補日は手動でもAIでも設定できます。

🔗 入口：ミーティング → 新規作成
  1. 対象範囲を選ぶ全員／チーム／パワーチーム・ゆるいチーム／個別に選択、のいずれか
  2. 候補日を設定する（下記いずれか、または両方を併用）
手動設定

🖊 カレンダーで自分で決める

カレンダー上で時間帯をクリック（選択中の長さで追加）またはドラッグ（30分単位）して候補日を追加する。自分の予定を見ながら設定できる。

AI設定

✨ 「AIで探す」で自動提案

対象メンバー全員の空き状況をもとに、AIが候補日時を自動で提案。すでに手動で追加した候補があれば「追加する」か「入れ替える」かを選べる。

  1. 参加者が候補日に○／△／✗で回答する
  2. 主催者が候補から確定日を選ぶ（複数日程の確定も可）全員の回答を待つ必要はなく、主催者の判断で確定できる
  3. 確定すると全員に通知される会議ツール連携があればURLも自動発行、主催者のカレンダーにもダブルブッキング防止のブロック予定が入る
💡「全員の承諾を待たなくてよい」「主催者がその場で確定できる」点は、1to1と共通する今回の改善ポイントとして触れると分かりやすいです。
6

協働機能の概要〜パワーチーム活動の記録〜アクションのフォロー

メンバー同士の関係性を可視化し、パワーチームでの活動と「次回までのアクション」を記録・引き継ぐ機能です。

🔗 入口：協働タブ
🕸 関係マップ 🌊 活動タイムライン ⚡ パワーチーム管理
  1. 協働マップで関係性を確認する誰と誰がつながっているか、パワーチーム・ゆるいチームの塊が円で表示される
  2. 条件を満たしたら「⚡ パワーチームを宣言」する
  3. 活動タイムラインから「＋ 活動を投稿する」「どんな活動をしたか」の本文に加え、「📋 次回までのアクション」を1件ずつではなくExcelのような一覧形式でまとめて入力できる（誰が・何を・いつまでに）
  4. アクションが完了したらチェックを入れる完了したものは取消線で表示。未完了のものは次回の同チームミーティングの案内や活動投稿時に自動で引き継がれる
  5. アクションだけ個別に公開範囲を設定できる活動本文はチャプター全体に公開しつつ、アクションだけチーム内限定にする、といった使い分けが可能
💡チーム管理パネルからもアクションの追加・確認ができます。「投稿を待たずにその場でアクションだけ足せる」点を見せると伝わりやすいです。
7

リファーラルさがし（ご縁さがし）

なかまの人脈をAIが横断的に検索し、有望な紹介の道筋を提案する機能です。2つの視点があります。

🔗 入口：ご縁タブ（✨アイコン）
視点A

🔍 私のためのご縁

自分の「金の卵・金のガチョウ」（欲しい相手像）に対して、なかまの人脈の中から候補をAIが探す。

視点B

🎁 貢献のためのご縁

自分の人脈を、なかま（最大5名まで指定可）の「金の卵・金のガチョウ」に紹介できないか、AIが探す。

  1. 視点（私のため／貢献のため）を選ぶ
  2. 到達方法（どこまで人脈を辿るか）を選ぶ1次（直接）／2次／3次 — 遠くまで辿るほど候補は広がるが確度は下がる
  3. 「この条件でさがす」を実行するAIが人脈データを照合し、有望な紹介の道筋と根拠を提示する
  4. 結果から直接アクションにつなげる「1to1を組む」「紹介する」のボタンからそのまま次の行動に移れる
💡実データで検索すると数十件ヒットする実例を見せると説得力があります。0件だった場合は「対象の登録内容が少ない」ことが多い旨を補足すると安心してもらえます。
